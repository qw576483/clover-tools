# 经验库（`experience/`）—— 从一个真实项目里摔出来的东西

> 这个文件夹不是"规范"，是**实战复盘**：我们真的从零做过一个 3D MMO 客户端（第三人称操作 + 地图导出 + 视野同步），
>（其中**地图导出 / 加载 / 客户端查询那一段已于 2026-09 下沉到引擎** —— 新项目不用再自己写，见 `3d-mmo-playbook.md` 步 2。）
> 也真的被用户来回骂了四轮。**每条经验都对应一次翻车**，写在这里是为了不再摔第二次。
>
> **使用时机**：
> - 用户说"做个 XX 游戏 / 一键出 XX / 删库重建一个 XX" → **先读 `experience/README.md` + `3d-mmo-playbook.md`**；
> - **用户说"卡 / 掉帧 / 有 1 帧吗" → 先读 `perf-triage.md`**（**先证伪环境，再查代码**）；
> - 写客户端操作/相机/移动同步之前 → `3d-mmo-playbook.md` +（症状速查）`patterns/client/3d-mmo-basics.md`；
> - 交付前自证/取证 → `verify-recipes.md`；
> - 感觉"又要做很久"时 → `time-sinks.md`（照着避开，能省掉大部分返工）；
> - 要照着写关键逻辑 → `3d-mmo-core-code/`（每段只有几十行，标注**分层落点**与"看什么"）。

## 一句话教训总表（按"代价"排序）

| 教训 | 代价（真实发生的） |
|---|---|
| **先搞懂引擎的"谁自动挂/谁必须业务挂"，再写业务代码** | 漏 `CloverRes.Init` ⇒ 模型**从头到尾没加载成功**，被误判成"同步问题"，白跑好几轮 |
| **三段一次做完**（启动/菜单/创角链路 + 首场景 + 游戏内流程；不许先交骨架） | 被用户连续四轮骂"半成品" |
| **不许"打开就直接进游戏场景"**（菜单链路不能省） | 用户："世界上没有完整版游戏会直接进到游戏场景里面" —— 一眼假 |
| **交付前必须自审"像不像参考游戏"**（不像 = 不可交付） | 只跑通就交 ⇒ 用户一句"不像"→ 全面返工；**没有参考游戏名就先问用户要** |
| **不许分步汇报**（做一项报一次） | 用户暴怒；他只想知道"做完没有" |
| **"卡 / 掉帧"先证伪环境，再查代码** | 跑满 6 次 Play 分析代码层性能红旗（射线 / HUD / 日志），而机器其实在跑 **WARP 软件渲染**（GPU 255ms/帧、3.5 fps）—— 根因在第 1 条命令 `SystemInfo.graphicsDeviceName` 里 |
| **移动/相机的标准做法先搜再做** | 被拽回、镜头穿墙，用户质疑"这种问题不是做游戏都会遇到的吗" |
| **移动同步三件套必须同时上**（本地碰撞 + 预测&校正&回放 + 停发闸门） | 少任何一条都表现为"按了键不动/被拽回" |
| **验收靠自证与截图，不靠"看着像"** | 用户看到的和 AI 以为的完全不是一回事 |
| **分层分模块** | Bootstrap 上帝类，改一处炸全局，被用户点名 |
| **改几何就重跑导出** | 客户端与服务端错位（客户端有墙、服务端不挡） |
| **量测优先**（第三方素材单位/枢轴、坐标格中心） | 模型 100 倍大 / 半埋 / 整体偏移半格 |
| **高频日志必须降频** | 一次断线刷 3262 条、一次未鉴权刷 747 条 |
| **驱动活编辑器**（别跑 batch） | 被"项目已在编辑器中打开"卡住，浪费大量等待 |
